# Magic Games · Presentación de Defensa (Tecnologías Informáticas 2026)

Slide deck web (8 diapositivas) en React + Vite + Tailwind CSS con dado d20 en Three.js.

```bash
npm install
npm run dev      # desarrollo
npm run build    # producción → dist/
```

Navegación: ← / → (también PageUp/PageDown, Espacio), Inicio/Fin, `F` = pantalla completa, swipe en táctil, `#N` en la URL abre la diapositiva N.

Variable opcional: `VITE_FRONTEND_URL` (URL de la SPA en Vercel mostrada en la diapositiva 8).
